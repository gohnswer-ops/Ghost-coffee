# اختبارات المشروع (محلية)

شغّل من مجلد المشروع:

```sh
bash tests/run_all.sh
```

يفحص الأمر صياغة JavaScript وJSON، ثم يجري اختبارات على نموذج اسم المستخدم/كلمة المرور وترحيل جلسة مجهولة قديمة، وسيناريوهات المحادثات والقصص والمجموعات عبر محاكي قواعد Realtime Database. هذه محاكاة محلية وليست اتصالاً بمصادقة Firebase الإنتاجية أو اختباراً على جهاز Android فعلي.
